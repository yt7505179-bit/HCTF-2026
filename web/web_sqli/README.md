# web_sqli

- **分类**：Web
- **难度**：入门
- **题型**：SQL 注入登录绕过（统一身份认证平台系列 · 签到题）
- **附件**：无

## 题面

还是那个统一身份认证平台——好消息：这一次账号密码校验是真的在查库。

登录进去，以管理员身份看一眼「网络安全宣传周内部公告」。

不知道怎么登？登录框右下角的「点击查看登录方法」会告诉你入门姿势。

- 登录框就是注入点，管理员账号就是最常见的那词：`admin`
- 前端会把输入里的空白字符全部去掉——payload 里一个空格都不能有
- 普通用户身份也能登进门户，但内部公告只对管理员可见

## 提示

1. 「点击查看登录方法」指向的搜索结果就是官方教程
2. 页面上可用的两个经典姿势：`admin'--` 与 `'or'1'='1'--`（注意没有空格）
3. 登录成功后前端会带着票据自动跳转门户，flag 就在管理员公告里

## 部署

```bash
docker build -t sqli ./src
docker run -d -p 58000:80 -e FLAG="hctf{xxx}" sqli
```

- 服务监听容器内 `0.0.0.0:80`（Nginx 网关 + FastAPI 后端同容器），宿主端口 `58000`
- **动态 flag**：平台向容器注入 `FLAG` 环境变量，启动时重播种写入库内
  管理员的「内部公告」字段（题内闭环）；未注入时使用代码内回退值
  （保持 `hctf{}` 格式）
- 管理员口令为 32 位随机十六进制，爆破/猜口令不可行，注入绕过是唯一正解
- 前端与 web_pathconfusion / web_leakedkey / web_headerauth 同一套
  统一身份认证平台 UI，属同系列题目；本题独立部署、独立可解
